## 🚀 How to Use

### 🟡 Google Colab Notebooks
1. Click **Open in Colab** next to any notebook below.
2. Connect to a GPU runtime: `Runtime → Change runtime type → T4 GPU`.
3. Run the cells in order from top to bottom.

### 🔵 Kaggle Notebooks
1. Click **Download (.ipynb)** next to any Kaggle notebook below *(downloads the `.ipynb` file directly)*.
2. Sign in at [kaggle.com](https://www.kaggle.com) → **Code** → **New Notebook**.
3. Go to `File → Import Notebook` and upload the downloaded `.ipynb` file.
4. In the right panel: `Session options → Accelerator → GPU T4 x2` (or `P100` where noted) and turn **Internet ON**.
5. Run all cells in order.
